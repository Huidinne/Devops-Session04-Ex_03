# Bài 3: Cấu hình xác thực SSH và đẩy dự án lên GitHub

## 1. Mục tiêu

* Tạo cặp khóa SSH sử dụng thuật toán Ed25519.
* Cấu hình xác thực SSH với GitHub.
* Liên kết repository cục bộ với repository từ xa thông qua giao thức SSH.
* Đẩy mã nguồn và lịch sử commit lên GitHub thành công.

## 2. Các bước thực hiện

### Bước 1: Tạo SSH key

Sử dụng lệnh:

```bash
ssh-keygen -t ed25519 -C "email_github_cua_ban@example.com"
```

Tạo cặp khóa SSH Ed25519 và lưu tại thư mục mặc định `~/.ssh/`.

Cặp khóa bao gồm:

* `id_ed25519`: khóa riêng, được bảo mật trên máy cá nhân.
* `id_ed25519.pub`: khóa công khai, sử dụng để cấu hình xác thực trên GitHub.

### Bước 2: Thêm SSH key vào GitHub

Sử dụng lệnh:

```bash
cat ~/.ssh/id_ed25519.pub
```

Sao chép nội dung khóa công khai và thêm vào mục **Settings → SSH and GPG keys** trên GitHub.

### Bước 3: Kiểm tra kết nối SSH

Sử dụng lệnh:

```bash
ssh -T git@github.com
```

Kết quả:

```text
Hi [username]! You've successfully authenticated, but GitHub does not provide shell access.
```

Kết quả xác nhận kết nối SSH với GitHub thành công.

### Bước 4: Cấu hình remote repository

Liên kết repository cục bộ với GitHub:

```bash
git remote add origin git@github.com:[username]/[repository].git
```

### Bước 5: Đẩy dự án lên GitHub

Sử dụng lệnh:

```bash
git push -u origin main
```

Sau khi thực hiện thành công, mã nguồn và lịch sử commit được tải lên repository từ xa.
